# E-commerce Sales Analysis Using MySQL

## Project Overview
This project focuses on analyzing e-commerce sales data using MySQL. The objective is to understand sales performance, customer purchasing behaviour, product performance, and geographical revenue distribution.

The project uses SQL queries to clean, transform, analyze, and generate meaningful business insights from retail transaction data.

## Dataset
- **Dataset:** Online Retail Dataset
- **Source:** UCI Machine Learning Repository
- **Period:** December 2010 – December 2011
- **Records:** 541,909
- **Country:** Multiple countries

## Tools and Technologies
- MySQL 8.0
- MySQL Command Line Client
- SQL

## Project Objectives
- Perform data cleaning and validation.
- Calculate important business KPIs.
- Analyze product and country-wise sales.
- Identify monthly sales trends.
- Analyze customer purchasing behaviour.
- Perform RFM analysis and customer segmentation.
- Generate business insights and recommendations.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries and CTEs
- CASE statements
- Window functions
- UNION and UNION ALL
- Temporary tables and views
- Stored procedures
- Indexes and transactions

## Key Findings
- Analyzed 541,909 original transaction records.
- Prepared 530,099 eligible sales records for analysis.
- Generated total eligible sales revenue of £10,655,622.48.
- Identified 19,959 unique orders and 4,338 identified customers.
- Found that the UK contributed approximately 84.6% of total revenue.
- Identified November 2011 as the highest-revenue month.
- Performed RFM analysis to segment customers into seven groups.
- Found that Champions contributed approximately 65% of customer-attributed revenue.

## Business Recommendations
- Strengthen customer retention through loyalty programs.
- Target At Risk and Hibernating customers with re-engagement campaigns.
- Investigate products with high sales volume but lower revenue.
- Explore growth opportunities in international markets.
- Prepare inventory ahead of high-revenue periods.
